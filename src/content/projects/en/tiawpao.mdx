# TiawPao

![TiawPao mobile application home screen](../../../assets/images/tiawpao.png)

## Overview

**TiawPao** is a travel planning application for trips within Thailand. Users can build itineraries themselves or ask AI to generate personalized travel plans using tourism information from the TAT DATA API.

## Key Features

- **Custom Itinerary Planning**: Create and organize a personal travel plan for destinations across Thailand.
- **AI-Generated Trips**: Generate personalized itineraries with AI based on the user's travel needs.
- **Destination Discovery**: Explore attractions, restaurants, food and drink spots, and recommended hotels.
- **Thailand Tourism Data**: Use destination information from the TAT DATA API to support trip planning.

## Tech Stack

- **Mobile Application**: React Native
- **Backend API**: Go and GoFiber
- **Database & ORM**: PostgreSQL and GORM
- **Cloud Services**: Firebase
