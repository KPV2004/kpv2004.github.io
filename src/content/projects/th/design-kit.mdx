# Design Kit

![Wireframe ของ Design Kit บนเดสก์ท็อป แท็บเล็ต และมือถือ](/images/design-kit.png)

## ภาพรวม

**Design Kit** คือ skill สำหรับ AI coding agent ที่ทำงานเหมือนนักออกแบบที่ส่งมอบงานให้ทีมพัฒนา เพียงอธิบายแอป ระบบจะสร้างทุกหน้าจอ ไม่ใช่แค่เส้นทางการใช้งานปกติ และคอยอัปเดตไฟล์ทั้งหมดให้สอดคล้องกันเมื่อมีการขอแก้ไข

## ฟีเจอร์หลัก

- **แหล่งข้อมูลหลักเพียงแห่งเดียว**: `design.md` เก็บสี (ทั้งโหมดสว่างและมืด) ตัวอักษร และไอคอน พร้อมตรวจคอนทราสต์ตามมาตรฐาน WCAG AA
- **Wireframe และ Mockup**: เริ่มจาก wireframe แบบ low-fi ของทุกหน้าจอ แล้วต่อด้วย mockup ที่คลิกได้ด้วย HTML และ Tailwind พร้อมตัวเลือกธีม
- **ไดอะแกรมสำหรับนักพัฒนา**: ไดอะแกรม User flow, ER, State, Sequence และ API contract ที่สอดคล้องกับหน้าจอ
- **UX Spec**: ตารางสถานะของแต่ละหน้าจอ ข้อความแจ้งข้อผิดพลาดแบบตรงตัว การโต้ตอบ และ copy deck ที่นักพัฒนานำไปสร้างได้ทันที
- **กระจายการเปลี่ยนแปลง**: การแก้ไขอย่าง "เพิ่มช่องเบอร์โทรศัพท์" จะอัปเดต wireframe, mockup, spec และไดอะแกรมไปพร้อมกัน
- **การตรวจสอบ**: มีสคริปต์ตรวจว่าทุกไฟล์สอดคล้องกันก่อนส่งมอบงาน

- **Outputs**: HTML, CSS และ JavaScript
