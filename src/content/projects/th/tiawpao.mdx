# TiawPao

![หน้าแรกของแอปพลิเคชันมือถือ TiawPao](/images/tiawpao.png)

## ภาพรวม

**TiawPao** คือแอปพลิเคชันวางแผนการท่องเที่ยวภายในประเทศไทย ผู้ใช้สามารถจัดแผนการเดินทางได้ด้วยตัวเอง หรือให้ AI สร้างแผนเที่ยวเฉพาะบุคคลจากข้อมูลการท่องเที่ยวของ TAT DATA API

## ฟีเจอร์หลัก

- **วางแผนการเดินทางเอง**: สร้างและจัดแผนการท่องเที่ยวส่วนตัวไปยังจุดหมายทั่วประเทศไทย
- **ทริปที่สร้างด้วย AI**: ให้ AI สร้างแผนการเดินทางเฉพาะบุคคลตามความต้องการของผู้ใช้
- **ค้นหาจุดหมาย**: สำรวจสถานที่ท่องเที่ยว ร้านอาหาร ร้านของกินและเครื่องดื่ม รวมถึงโรงแรมแนะนำ
- **ข้อมูลการท่องเที่ยวไทย**: ใช้ข้อมูลจุดหมายจาก TAT DATA API ประกอบการวางแผนทริป

## เทคโนโลยีที่ใช้

- **แอปพลิเคชันมือถือ**: React Native
- **Backend API**: Go และ GoFiber
- **ฐานข้อมูลและ ORM**: PostgreSQL และ GORM
- **บริการคลาวด์**: Firebase
